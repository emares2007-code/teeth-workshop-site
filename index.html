The project

About Teeth Workshop

An original native Windows place editor inspired by approachable mid-2010s building workflows, with its own identity and implementation.

The editor today

The C++ editor uses Qt 6 for its interface and DirectX 11 for the scene viewport. Its foundation includes Parts, Models, Folders, a .tblx place format, Play Solo, classic-style lighting, Box3D physics, and sandboxed Luau scripts.

The website later

The long-term direction includes creator profiles, discoverable games, published places, and an asset library. These need accounts, durable storage, moderation, and a secure backend. This GitHub Pages prototype is not that backend.

Independent by design

Teeth Workshop is not affiliated with Roblox Corporation. The project studies usability of older creation tools but does not use Roblox branding, proprietary code, or copied website artwork.
