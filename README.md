# Teeth Workshop website

This is the public development portal for Teeth Workshop, an independent Windows world-building editor. The website has Games, Create, Profile, and About sections. Game listings are labeled examples; creation drafts and profile edits are stored in your browser only. There are no online accounts, uploads, published games, or cloud data yet.

## Development path

1. **Static portal (current):** browse example places, create local drafts, and preview a local profile.
2. **Account and publishing service:** add authentication, a durable user/place database, privacy controls, and publishing APIs.
3. **Assets and play sessions:** add reviewed uploads, storage, moderation, and secure launching from the Windows client.

GitHub Pages hosts only this static front end. Engine source, scene files, personal data, and credentials are not part of this repository. The site uses typography and neutral placeholders only; project artwork will be supplied by the owner later.
